🔧 Git Kurulum
Kod güncellemeyi kolaylaştır — scp'den kurtar
🎯 Hedef

Şu an her değişiklik için scp kullanıyorsun. Git kurulunca:
Mac'te değişiklik yap → git push → sunucu otomatik güncellenir.

1️⃣ Sunucuda Git Repo Kur

SSH ile sunucuya bağlan ve şu komutları çalıştır:

1
Git'i başlat
Proje dizinine git, repo oluştur
cd /var/www/aofnotlar git init git add . git commit -m "ilk commit"
2
GitHub'a bağla
GitHub'da yeni private repo aç (aofnotlar), sonra:
git remote add origin https://github.com/KULLANICIADI/aofnotlar.git git branch -M main git push -u origin main
3
.gitignore oluştur
.env ve node_modules'ü dışarıda tut
cat > /var/www/aofnotlar/.gitignore << 'EOF' node_modules/ frontend/node_modules/ frontend/build/ .env *.log EOF
2️⃣ Mac'te Kur
4
Mac'e clone et
Mac terminalinde:
cd ~/Projects # veya istediğin dizin git clone https://github.com/KULLANICIADI/aofnotlar.git cd aofnotlar
3️⃣ Otomatik Deploy Scripti (Sunucuda)
5
deploy.sh scripti oluştur
Sunucuda bu scripti çalıştırınca her şey güncellenir:
cat > /var/www/aofnotlar/deploy.sh << 'EOF' #!/bin/bash echo "🔄 Deploy başlıyor..." cd /var/www/aofnotlar git pull origin main npm install --production cd frontend npm install npm run build cd .. pm2 restart aofnotlar echo "✅ Deploy tamamlandı!" EOF chmod +x /var/www/aofnotlar/deploy.sh
⚡ Günlük Kullanım

Mac'te değişiklik yaptıktan sonra:

## Mac'te: git add . git commit -m "değişiklik açıklaması" git push ## Sonra sunucuda (SSH ile): cd /var/www/aofnotlar && ./deploy.sh
💡 İlerisi için: GitHub Actions ile push yapınca sunucu otomatik deploy olabilir. İstersen o adımı da ekleriz.
